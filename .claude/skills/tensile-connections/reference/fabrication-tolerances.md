# Fabrication, tolerances and hardware for connection parts

## Execution (EN 1090-2)
* Execution class: CC2 canopies → EXC2; fatigue/flutter-prone lugs and cable anchorages → EXC3; CC3 stadium roofs → EXC3 [V].
* Holes for fit bolts and fitted pins: **ISO 286-2 class H11** [V]; general hole tolerance ±0.5 mm [V].
* Pin clearance: AISC ≤ 1 mm for moving pins [V]; EC3 has no fixed number but σ_h penalises clearance. "≤ 0.1d" is **not** a code rule.
  Practice: 0.5–1.0 mm for d ≤ 60 mm, about 1–2 mm for larger pins [U].
* Fork gap vs lug: about 1–3 mm total clearance, shimmed if larger [U].
* Galvanising: ream holes after galvanising or size the clearance for the zinc; stainless or plated pins with collars or split pins.
* Flatness and hole position: EN 1090-2 Annex B (essential) and Annex D (functional, e.g. Table D.2.8) [V].
* NDT Table 24: VT 100 %; transverse butt/partial-penetration in tension U ≥ 0.5: EXC2 10 %, EXC3 20 %, EXC4 100 % [V]; fillet % read the table [U].
  UT or MT for lug butt welds. WPS/WPQR to EN ISO 15614; preheat EN 1011-2.
* No field welding: site connections pinned or bolted [V].

## Aluminium and stainless parts
* Extrusions 6005-T6 / 6063-T5/T6 / 6061-T6 / 6082-T6; anodise or powder coat.
* Fixings A2/A4-70/80 (EN ISO 3506).
* Bimetallic isolation: washers + sleeves + tape; see `fabric-steel-connections.md`.
